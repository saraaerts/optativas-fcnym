# Materias optativas · FCNyM (prototipo)

Prototipo de un espacio interactivo para explorar las materias optativas de la Facultad de Ciencias Naturales y Museo (UNLP) por carrera.

- Elegí una carrera para ver sus optativas.
- Tocá una materia para ver descripción, video de la cátedra y, en algunas, un objeto 3D.
- Los textos entre [corchetes] son contenido a completar.

Los datos salen de la tabla publicada en la web de la Facultad (de la A a «Protección…»). Para editar materias, descripciones o qué materias tienen 3D, modificá las listas `MATERIAS`, `DESCRIPCIONES` y `CON_3D` al comienzo del `<script>` en `index.html`.
